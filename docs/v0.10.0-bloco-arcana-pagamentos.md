# Crypt v0.10.0 — Cobrança real da Arcana

## Provedor

Mercado Pago — API de Assinaturas sem plano associado.

## Preço

R$ 5,00 por mês, em BRL, com frequência mensal.

O preço é definido somente na Edge Function pelo secret:

`ARCANA_MONTHLY_PRICE_BRL=5.00`

O cliente não envia preço, moeda, e-mail nem identificador do perfil.

## Fluxo

1. A pessoa autenticada clica em **Assinar por R$ 5/mês**.
2. A Edge Function obtém o e-mail diretamente do Supabase Auth.
3. O backend cria uma assinatura pendente no Mercado Pago.
4. O checkout oficial é aberto fora do Crypt.
5. O Mercado Pago retorna para a página pública da Edge Function.
6. O deep link `crypt://arcana/callback?status=return` reabre Windows ou Android.
7. O Crypt sincroniza a assinatura diretamente com o Mercado Pago.
8. Webhooks mantêm pagamento, renovação, atraso, pausa e cancelamento atualizados.
9. Benefícios são liberados somente após uma fatura com pagamento aprovado.

## Webhooks

Endpoint:

`/functions/v1/arcana-billing/webhook`

Eventos aceitos:

- `subscription_preapproval`;
- `subscription_authorized_payment`;
- `payment`.

Toda notificação exige:

- `x-signature`;
- `x-request-id`;
- `data.id`;
- HMAC SHA-256 com o segredo do Webhook.

Depois da assinatura válida, o backend consulta o recurso novamente na API do
Mercado Pago. O payload recebido não é usado como fonte final de verdade.

## Idempotência

`arcana_billing_payments` possui uma linha por fatura do provedor.

Uma mesma fatura aprovada pode ser enviada várias vezes, mas aumenta a jornada
Arcana somente na primeira transição para `approved`.

## Cancelamento

Cancelar pelo Crypt envia `status=cancelled` ao Mercado Pago.

Não são feitas novas cobranças. O período já pago permanece ativo até
`current_period_ends_at`.

## Atraso

Uma fatura rejeitada altera o estado para `past_due` e cria uma tolerância de
três dias, sem encurtar um período já pago.

## Privacidade

O Crypt não recebe nem armazena:

- número de cartão;
- código de segurança;
- documento informado no checkout;
- token do cartão.

O banco guarda somente IDs do provedor, estado, valor, moeda e datas necessárias
para liberar os benefícios e impedir processamento duplicado.
