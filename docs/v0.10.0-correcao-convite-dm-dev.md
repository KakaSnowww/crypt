# Correção do convite por DM no modo dev

A correção altera o fluxo para:

- reutilizar uma DM direta já existente;
- chamar `open_direct_conversation` somente quando necessário;
- refazer a consulta de conversas como recuperação de corrida/realtime;
- criar o convite sem mostrar sucesso prematuro;
- mostrar sucesso somente depois que `send_direct_message` concluir;
- mostrar etapa e detalhes técnicos no modo de desenvolvimento;
- registrar o objeto completo do erro no console do Electron/Vite.

Nenhuma migration é necessária.
