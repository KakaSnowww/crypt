# Crypt v0.10.0 — Arcana com Asaas

## Provedor

Asaas Checkout com assinatura recorrente.

O Checkout é hospedado pelo próprio Asaas. O Crypt nunca recebe os dados do
cartão.

## Preço

R$ 5,00 por mês.

O valor fica no secret do backend:

`ARCANA_MONTHLY_PRICE_BRL=5.00`

O cliente não envia valor, moeda, e-mail ou identificador de perfil para
definir a cobrança.

## Forma de pagamento

O checkout recorrente usa cartão de crédito, permitindo renovação automática
mensal. O próprio Asaas coleta e valida os dados.

## Fluxo

1. A pessoa autenticada clica em **Assinar por R$ 5/mês**.
2. A Edge Function cria um Checkout recorrente no Asaas.
3. O Crypt abre somente um link HTTPS oficial do domínio `asaas.com`.
4. O pagador conclui a assinatura fora do aplicativo.
5. O Asaas redireciona para uma página pública da Edge Function.
6. O deep link `crypt://arcana/callback?status=return` reabre Windows ou Android.
7. O Crypt consulta o Asaas.
8. O Webhook confirma o pagamento.
9. Os benefícios são liberados somente após `PAYMENT_CONFIRMED` ou
   `PAYMENT_RECEIVED`.

## Webhook

O configurador cria ou atualiza automaticamente o Webhook **Crypt Arcana**.

Eventos:

- `CHECKOUT_PAID`;
- `CHECKOUT_CANCELED`;
- `CHECKOUT_EXPIRED`;
- `PAYMENT_CONFIRMED`;
- `PAYMENT_RECEIVED`;
- `PAYMENT_OVERDUE`;
- `PAYMENT_CREDIT_CARD_CAPTURE_REFUSED`;
- `PAYMENT_REFUNDED`;
- `PAYMENT_CHARGEBACK_REQUESTED`.

O token de autenticação possui 64 caracteres e é enviado no header
`asaas-access-token`.

## Idempotência

O mesmo evento pode ser reenviado pelo Asaas. A tabela
`arcana_billing_events` usa o ID do evento como chave primária.

A tabela `arcana_billing_payments` usa o ID da cobrança como chave primária.
Uma cobrança confirmada aumenta a Jornada Arcana somente uma vez, mesmo que
posteriormente também seja recebido `PAYMENT_RECEIVED`.

## Cancelamento

O Crypt remove a assinatura pelo endpoint oficial do Asaas, impedindo novas
cobranças.

O acesso já pago continua até `current_period_ends_at`.

## Atraso e estorno

- atraso ou recusa: `past_due` com tolerância de três dias;
- estorno ou chargeback: acesso encerrado e estado `expired`.

## Ambientes

Sandbox:

`https://api-sandbox.asaas.com/v3`

Produção:

`https://api.asaas.com/v3`

O configurador pede o ambiente e valida a API Key antes de alterar o projeto
remoto.

## Segurança

Secrets necessários:

- `ASAAS_API_KEY`;
- `ASAAS_API_BASE_URL`;
- `ASAAS_WEBHOOK_TOKEN`;
- `ASAAS_WEBHOOK_NOTIFICATION_EMAIL`;
- `ARCANA_MONTHLY_PRICE_BRL`.

Nenhum deles entra no repositório.
