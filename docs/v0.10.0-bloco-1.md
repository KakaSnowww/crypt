# Crypt v0.10.0 — Bloco 1

Este bloco inicia a atualização Arcane Reforge com foco em estabilidade e experiência diária.

## Entregue neste pacote

- YouTube temporariamente marcado como “Em breve”, sem iniciar OAuth.
- Links HTTP e HTTPS clicáveis em canais, DMs e grupos privados.
- Convites do Crypt reconhecidos nas mensagens e exibidos como cards.
- Página de convite redesenhada com identidade arcana.
- Inicialização com o Windows corrigida para o aplicativo instalado.
- Estado claro quando a opção é testada em modo de desenvolvimento.
- Auditoria automática para detectar textos corrompidos por codificação.

## Não alterado

O arquivo `supabase/functions/external-oauth/index.ts` não é substituído por este pacote, preservando a correção local do retorno OAuth.
