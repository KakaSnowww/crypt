# Crypt v0.10.0 — Contas Conectadas

## Escopo

Este bloco coloca em produção as integrações já existentes:

- Spotify OAuth 2.0 com PKCE;
- Google OAuth 2.0 para YouTube;
- Steam OpenID;
- tokens OAuth cifrados no backend;
- sincronização manual;
- atividade atual do Spotify;
- perfil, avatar e biblioteca pública da Steam;
- canal e estatísticas públicas do YouTube;
- visibilidade individual no perfil;
- desconexão com remoção de tokens e atividade.

## Segurança

As credenciais não entram no código e não devem ser enviadas por chat.

O script `CONFIGURAR-CREDENCIAIS-OAUTH.ps1`:

1. pede os valores localmente;
2. envia os secrets diretamente para o Supabase;
3. cria uma chave AES-256;
4. protege a cópia local dessa chave com o DPAPI do Windows;
5. reutiliza a mesma chave em execuções futuras;
6. aplica migrations;
7. publica a Edge Function `external-oauth`;
8. grava somente as URLs públicas de callback.

A chave protegida fica em:

`%APPDATA%\Crypt\external-connections-encryption-key.dpapi`

Não apague esse arquivo depois que contas forem conectadas. Trocar a chave sem migrar os
tokens torna os tokens antigos impossíveis de decifrar.

## Callbacks

As URLs são geradas automaticamente a partir de `VITE_SUPABASE_URL`.

Formato:

- Spotify: `/functions/v1/external-oauth/callback/spotify`
- Google/YouTube: `/functions/v1/external-oauth/callback/youtube`
- Steam: `/functions/v1/external-oauth/callback/steam`

## Fluxo

1. Aplicar o bloco.
2. Executar `scripts\CONFIGURAR-CREDENCIAIS-OAUTH.bat`.
3. Cadastrar as callbacks impressas no Spotify e no Google Cloud.
4. Executar `scripts\VERIFICAR-CONTAS-CONECTADAS.bat`.
5. Abrir **Configurações → Contas conectadas**.
6. Testar Spotify, Steam e YouTube.
7. Ativar **Mostrar no perfil**.
8. No Spotify, ativar **Mostrar atividade**.
