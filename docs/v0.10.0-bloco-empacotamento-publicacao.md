## Build local

`scripts/GERAR-BUILD-LOCAL-v0.10.0.bat` gera:

- instalador Windows local;
- blockmap;
- `latest.yml`;
- APK debug para teste;
- `SHA256SUMS.txt`;
- resumo da pasta.

O APK debug não é a versão oficial de produção.

## Publicação oficial

`scripts/PUBLICAR-v0.10.0-APOS-VALIDACAO.bat`:

1. exige branch `main`;
2. confirma o remote correto;
3. verifica login do GitHub CLI;
4. verifica nomes dos secrets e variables;
5. impede arquivos sensíveis rastreados;
6. impede tag duplicada;
7. exige confirmação digitada;
8. executa validações Windows e Android;
9. cria commit e tag;
10. envia a tag para o GitHub.

A tag dispara os workflows oficiais.

## Artefatos oficiais

Windows:

- instalador NSIS;
- blockmap;
- latest.yml;
- checksum SHA-256.

Android:

- APK assinado;
- AAB assinado;
- checksum SHA-256 de ambos.

## Segurança

- nenhum segredo é incluído no ZIP;
- keystore continua nos GitHub Actions Secrets;
- `google-services.json` é reconstruído durante o workflow;
- publicação não acontece ao instalar o bloco;
- o script oficial deve ser usado somente após a validação final.
