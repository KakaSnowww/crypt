# Crypt v0.10.0 — Editor de Imagens estilo Discord

## Resultado

O editor compartilhado é usado em:

- avatar do perfil;
- banner do perfil e da chamada;
- ícone do servidor;
- banner do servidor;
- outras telas que já usavam `ImagePositionEditor`.

## Controles

- arrastar diretamente a imagem;
- roda do mouse para zoom;
- setas do teclado para precisão de 1%;
- Shift + seta para precisão de 5%;
- `+` e `-` para zoom;
- tecla `R` para redefinir;
- controles horizontais, verticais e de zoom;
- pontos rápidos: esquerda, centro, direita, topo e base;
- grade de composição opcional;
- valores numéricos visíveis.

## Avatar e banner já salvos

O perfil passa a mostrar `Reenquadrar atual`.

Essa ação altera somente:

- `avatar_position_x`;
- `avatar_position_y`;
- `avatar_zoom`;
- `banner_position_x`;
- `banner_position_y`;
- `banner_zoom`.

O arquivo não é reenviado e não gera uma nova cópia no Storage.

## Novo arquivo

Ao selecionar ou arrastar uma imagem:

1. o arquivo é validado;
2. uma URL local é criada;
3. o editor abre;
4. nada é enviado antes de `Salvar enquadramento`;
5. cancelar libera a URL local;
6. depois do sucesso, a consulta do perfil é atualizada.

## Servidores

O fluxo já existente de servidor continua seguro:

1. o proprietário seleciona a imagem;
2. o editor compartilhado define o recorte;
3. imagens estáticas são exportadas com suavização de alta qualidade;
4. ícones são limitados a 1024 px;
5. banners são limitados a 1920 px;
6. o arquivo validado é enviado pela ação existente.

GIFs continuam preservando a animação.

## Compatibilidade

Foi mantida a mesma assinatura pública de `ImagePositionEditor`, então telas
anteriores não precisam ser recriadas.

O processamento também possui fallback para navegadores sem
`createImageBitmap`.
